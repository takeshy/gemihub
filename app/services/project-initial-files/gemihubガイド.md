# GemiHub ガイド

このプロジェクトへようこそ。GemiHubでは、Markdown文書、表、Canvas、ワークフローなどをプロジェクト内で管理し、AIと一緒に編集できます。

## はじめに

1. 左のツリーでこのファイルを選び、編集モードで内容を書き換えます。
2. 「新規作成」からMarkdownなどのファイルを追加できます。
3. AIチャットでは、作成・要約・校正など、行いたいことをそのまま依頼できます。
4. 高度な機能は「Settings → General → Advanced features」で必要なものだけ有効にできます。

## プロジェクトとPersonal

- 通常のプロジェクトは、組織でアクセス権を持つメンバーと共有されます。
- Personalは本人専用で、ほかのユーザーには表示されません。
- Personalと通常プロジェクトの間では、ファイルをドラッグ＆ドロップして移動できます。

このファイルは自由に編集または削除できます。
